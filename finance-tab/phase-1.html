Context
The Finance tab turns the books into a read-mostly view in the Northlight OS, one phase at a time. Rules for every phase: a mockup is approved before a screen is built, an AIMS-004 amendment is approved before any new write, and every change is a pull request that Elizabeth merges. The full plan is dashboard/specs/FINANCE-TAB-PROJECT-BRIEF.md in the dispatcher repo.
