# Northlight Connections

**Status:** Building  
**Registered:** 2026-11-05  
**Last refreshed:** 2026-11-12

## What it is
A private, local tool that tracks (never sends) Elizabeth's real conversations with her LinkedIn connections, replacing a strained 18-tab spreadsheet. It reads her own LinkedIn data export (not the LinkedIn API) and keeps everything in one local file on her computer.

## Tool goals
1. No one falls through the cracks: nobody who messaged me waits unanswered for 14+ days without it showing on Today.
2. More real conversations: coffee chats held per month (target to be set by Elizabeth).
3. No wasted coffees: job-seekers and non-fits are tagged and never get a coffee offer.
4. Even workload: follow-ups never exceed the daily cap (10 a day), at random 9–19 day intervals.
5. Privacy holds: no message text stored, no real data in the repo, everything local.
6. Small and hers: one computer, no paid CRM, replaces the 18-tab sheet.
