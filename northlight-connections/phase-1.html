What we are building
A small, private, local tool that tracks (never sends) Elizabeth's real conversations with her LinkedIn connections. It reads her own LinkedIn data export, keeps everything in one local file, and never stores message text. Phase 1 is the first working draft: import the export, show people, tag them, track stages, and show a Today list. Phase 1 is done when Draft 1 runs on her real export, she trusts the Today list, and she no longer needs the spreadsheet for follow-ups.
Tool Goals (aspirational)
1. No one falls through the cracks
Nobody who messaged me waits unanswered for 14+ days without it showing on Today.
2. More real conversations
Coffee chats held per month. Target to be set.
3. No wasted coffees
Job-seekers and non-fits are tagged and never get a coffee offer.
4. Even workload
Follow-ups at random 9–19 day intervals, never more than the daily cap (10 a day).
5. Privacy holds
No message text stored, no real data in the repo, everything local.
6. Small and hers
One computer, no paid CRM, replaces the 18-tab sheet.

Decisions Log
1. Tracks, never sends
Every message is written and sent by hand. No automation of LinkedIn.
2. Message text is never stored
Messages are read in memory only for date, direction and whether the coffee link was in the message.
3. Local file, not a hosted database
One local SQLite file outside OneDrive keeps people data on her own computer.
4. Built on the LinkedIn export, not the API
The API has no people-level data, messages or connection list.
5. Core separate from any window
Browser UI on localhost first; Electron can wrap it later if wanted.
