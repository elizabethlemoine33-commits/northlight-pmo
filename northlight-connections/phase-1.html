Tool Goals (aspirational)
1. No one falls through the cracks
Nobody who messaged me waits unanswered for 14+ days without it showing on Today.
2. More real conversations
Coffee chats held per month. Target set: 6 per month, shown on Today and Goals.
3. No wasted coffees
Job-seekers, non-fits and clients are kept out of coffee goals.
4. Even workload
Follow-ups at random 9–19 day intervals, never more than the daily cap (10 a day).
5. Privacy holds
No message text stored, no real data in the repo, everything local, a Forget this person option on every card.
6. Small and hers
One computer, no paid CRM, replaces the 18-tab sheet.

Decisions Log
1. Tracks, never sends
Every message is written and sent by hand. No automation of LinkedIn.
2. Message text is never stored
Messages are read in memory only for date, direction and whether the coffee link was in the message.
3. Local file, not a hosted database
One local SQLite file outside OneDrive keeps people data on her own computer.
4. Built on the LinkedIn export, not the API
The API has no people-level data, messages or connection list.
5. Stage belongs to a goal, not the person
A person can be in several goals, each with its own stage from a shared stage library with definitions.
6. Relationship is its own field; tags are flags
Relationship: Contact, Lead, Active client, Past client, Referral partner, Peer. Tags: Warm and Invite (green), Job-seeker and Not a fit (red).
7. Declined is not Do not contact
Declined means not now. Do not contact is a separate, deliberate two-step action with a red banner.
8. Change history is append-only; Forget this person deletes it
Audit-ready history, with privacy winning when a person is forgotten on purpose.
10. A desktop app, not a terminal (Nov 11)
An Electron window and Windows installer run the same local app on the same data file. Unsigned installer, so Windows warns once.
11. Coffee-chat target: 6 per month, kept in the app (Nov 11)
The target lives on the goal in Connections. Who she meets is not tracked in ClickUp.
12. People not on LinkedIn: a hand-added record is kept on merge (Nov 11)
Every person has an internal ID; the LinkedIn address is optional. When the same person later arrives from LinkedIn, she reviews the merge: the hand-added record keeps its history and takes the address.
13. Suggestions are never applied automatically (Nov 11)
Title rules propose a relationship or tag; Elizabeth accepts or skips each one.
14. Brand look: light page, dark top bar, brand accents (Nov 11)
Teal and pink outline boxes, dusk purple marks the current stage, gradient on main buttons. Green and red keep their one meaning (pursue and do not pursue).
15. Connectors agreed for the next phase (Nov 11)
(a) Local read-only connector so Claude can query the data as a database, with as few names as possible; (b) one-way ClickUp reminders for follow-ups due today, carrying the LinkedIn profile link instead of a name; (c) Calendar matching that proposes coffee-chat matches she confirms. Each gets a short written plan before it is built.
9. Merge a PR only when the build is final
PR 6 was merged before its last commit landed, so a follow-up PR 7 was needed.
