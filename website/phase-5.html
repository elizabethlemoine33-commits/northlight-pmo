Agent Content Standards — Wire Into Pipeline
Standards for OS Marketing + Content Pipeline Agents
Status: Not Yet Written
The formal agent standards document will be written after the first 5 posts are migrated and the QR audit is run. Standards will be derived from audit findings. Placeholder requirements below — finalize during migration.
StandardRequired ByRule
PIPEDA Link
Every post mentioning PIPEDA
Must hyperlink the word "PIPEDA" to https://www.priv.gc.ca/en/privacy-topics/privacy-laws-in-canada/the-personal-information-protection-and-electronic-documents-act-pipeda/ — every time it appears. No exceptions. Standing rule since Phase 4.
Stat Citations
Every post with a number, percentage, or claim attributed to a source
All statistics must cite source inline or in a footnote. Minimum: source name + year. Preferred: hyperlink to primary source document. If stat cannot be traced to a primary source, rephrase or remove. "Nearly 45%" (not "nearly 50%") for CFIB 2026 AI adoption figure.
Author Byline
All posts
Visible byline "By Elizabeth Lemoine" below the post title with link to /about.html. Jekyll template will render this from front matter author field — agents set author: Elizabeth Lemoine in front matter.
Ordered Lists for Steps
Any post with sequential steps, a process, or a how-to
Use <ol> not <ul> for sequential steps. GEO requirement — numbered lists are more citable by AI engines. Unordered lists fine for non-sequential items.
Answer Blocks
All posts
Each major H2 should be followed by a concise 2–3 sentence direct answer block (class="answer-block") before the supporting detail. This is the GEO/AEO core signal — AI engines extract these for citations.
FAQPage Schema
All posts with a FAQ section
If a post has Q&A content, include FAQPage JSON-LD schema. Minimum 3 Q&As. Questions must match the visible H3 headings in the FAQ section exactly.
OG Tags Complete Set
All posts
Required: og:type (article), og:title, og:description, og:url, og:image (northlight-og-image.png), og:site_name (Northlight Advisory Services), article:author, article:published_time. Twitter Card: summary_large_image + title + description + image. Jekyll template enforces via front matter.
Canonical Tag
All posts and pages
Self-referential canonical tag required on every page. Points to the absolute URL of the page itself. Jekyll template generates from front matter permalink or page.url.
Date-in-URL Policy
Stat-heavy, listicle, and tools-guide posts
Year in URL (e.g., -2026) is valid and encouraged for posts where data expires annually. One canonical version at a time — always set up a redirect before retiring the old URL if it may have been indexed. Evergreen thought pieces: no year in URL.
