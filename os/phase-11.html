Phase 11 Learnings
Railway filesystem = wrong store for any cross-session state
Harper's standing brief was written to the filesystem first. The deploy caveat was caught immediately and the fix was applied in the same session. Pattern: if a write is meant to persist beyond a single request, it goes to Drive. No exceptions for Round Table state.
Echo-back channel routing creates noise when the reply isn't for that channel
The stale approval message used event.channel — the correct pattern for command replies, but wrong for system cleanup messages. When a message is operational (not a response to a user action), it should either go to a fixed ops channel or be silenced. Not echoed back.
Strategy decisions need an OS anchor before execution begins
The LinkedIn strategy was finalized at the advisory board level (Aug 3) but the OS had no knowledge of it — no doctrine update, no orchestrator context, no tag infrastructure. Phase 12 exists entirely because the strategy-to-OS handoff was missing. The gap: advisory board outputs a document; OS doesn't ingest it automatically.
