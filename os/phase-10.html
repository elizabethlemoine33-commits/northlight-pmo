Phase 10 Learnings

Corrected mid-session. Create a Slack Incoming Webhook at api.slack.com/apps, paste URL into Railway notifications. Took ~2 minutes once the mechanism was clear.
Define log scope boundary before instrumenting, not after
Without a boundary, each new job feels like a candidate. Casey's question surfaced this before Phase C shipped — the answer is now documented and the 90-day review locks it in.

Railway notification was live before the first Phase B push. The deploy confirmation appeared in #northlight-build-log without any manual check. Worth keeping as a sequencing practice.
